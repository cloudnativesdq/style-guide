Small uppercase pill label for event type tags, sold-out/spots-remaining flags, and section eyebrows.

```jsx
<Badge variant="accentSoft">Meetup</Badge>
<Badge variant="warning">3 lugares disponibles</Badge>
<Badge variant="destructive">Sold Out</Badge>
```

Variants: default (solid accent), secondary, destructive, warning, outline, accentSoft (tinted accent — the most-used variant on event cards). Always uppercase, `font-heading`, `tracking-wide`.
